# Tool Slice PIP

Windows용 .NET 10 WPF 도구 모음의 창 PIP 기능입니다. Windows 10 2004 이상에서 `tool gui`로 실행합니다.

## 사용

- **창 PIP**: 창 목록에서 원본을 선택하고 `선택한 창 띄우기`를 누릅니다.
- **창 일부 선택**: 버튼을 누르고 원본 창의 원하는 부분을 드래그합니다. `Esc`는 취소합니다.
- PIP 상단을 드래그해 이동하고 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. `×`로 닫습니다.
- PIP 영상에서 클릭·휠·드래그할 수 있습니다. 클릭과 드래그는 마우스를 놓을 때 원본 창에 전달됩니다. 전달 순간 원본 창이 활성화되고 포인터가 잠시 이동합니다.

## 구조

- `WindowCatalog`: 캡처 가능한 HWND 열거와 현재 창 위치 조회
- `SelectionOverlay`, `WindowTarget`: 창 일부 선택과 창 기준 비율 좌표 저장
- `GraphicsCaptureService`: Windows Graphics Capture 프레임 수신, Direct3D11에서 선택 부분만 GPU 복사 후 최대 약 15 FPS 읽기
- `PipWindow`: 항상 위에 표시되는 PIP, 표시 크기에 맞춘 입력 좌표 변환, 세션 상태 표시
- `InputForwarder`: Windows `SendInput`으로 원본 창에 마우스 제스처 전달

각 PIP가 독립된 캡처 세션을 가집니다. 원본 창이 닫히면 해당 PIP도 닫힙니다. 창이 이동하거나 크기가 바뀌면 선택 부분의 창 기준 비율을 유지합니다.

## 제한

Windows Graphics Capture는 영상만 제공합니다. 입력 전달은 별도로 수행하며 원본 앱을 활성화할 수 있습니다. 관리자 권한 앱, 보호 콘텐츠, 게임의 Raw Input 또는 일부 자체 입력 엔진은 캡처나 입력을 거부할 수 있습니다. 앱은 권한 상승이나 Windows 보안 제한 우회를 시도하지 않습니다. 캡처가 실패하거나 프레임이 멈추면 PIP 하단에 상태를 표시합니다. 드래그는 PIP에서 놓은 뒤 원본에 재생되므로 원본의 변화가 드래그 중 실시간으로 보이지 않습니다.

WGC 캡처와 영역 복사는 GPU에서 처리하지만 WPF 표시에 필요한 선택 영역 픽셀은 CPU 메모리로 읽습니다. 매우 큰 영역이나 여러 PIP를 동시에 사용하면 CPU 사용량이 늘 수 있습니다.
