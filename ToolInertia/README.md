# Tool Inertia

Windows 10/11용 WinForms 창 관성 이동 유틸리티입니다. 다른 프로세스에 DLL을 주입하거나 관리자 권한을 요구하지 않습니다.

## 빌드와 실행

Visual Studio에서 `ToolInertia.csproj`를 열고 Release로 빌드하거나 다음 명령을 실행하세요.

```powershell
dotnet build .\ToolInertia.csproj -c Release
dotnet run --project .\ToolInertia.csproj -c Release
```

현재 대상 프레임워크는 .NET 10입니다. 실행 PC에는 .NET 10 Desktop Runtime이 필요합니다. `tool slipperyWindow`를 입력하면 켜지고 다시 입력하면 꺼집니다. 실행하면 시스템 트레이에 아이콘이 나타납니다. 우클릭으로 관성을 끄거나, 설정을 열거나, 종료할 수 있습니다. 설정은 `%LOCALAPPDATA%\ToolInertia\settings.json`에 저장됩니다. 시작 프로그램은 현재 사용자 `Run` 레지스트리에 등록됩니다.

## 동작 원리

`SetWinEventHook`으로 일반 창의 `EVENT_SYSTEM_MOVESIZESTART/END`를 감지합니다. 시작 시 왼쪽 버튼이 눌린 창만 추적하고, 드래그 중 실제 창 좌표를 약 8ms 간격으로 기록합니다. 저수준 마우스 훅은 왼쪽 버튼 해제 시각과 재클릭을 알려줍니다. Windows의 기본 이동이 끝난 뒤에만 최근 약 100ms의 좌표로 속도를 계산합니다. 크기 변경, 클릭만 한 경우, 오래된 이동 기록은 제외합니다.

관성은 `v(t)=v₀ exp(-마찰력·t)`로 감속합니다. 실제 프레임 간 시간을 사용하며, 모든 관성이 끝나면 타이머를 정지합니다. 드래그 중에는 창 위치를 보정하지 않고, 화면 밖에서 마우스를 놓으면 부드럽게 안쪽으로 돌아옵니다. 관성으로 디스플레이 경계에 빠르게 닿으면 출발 속도도 반영해 창의 일부가 보이는 범위에서 최대 320픽셀까지 넘어갔다가 돌아오고, 느리게 닿으면 튀지 않고 가장자리에서 18픽셀 떨어진 위치에 자리 잡습니다. PerMonitorV2 DPI 모드에서 물리 픽셀 좌표를 사용합니다.

## 확인 절차

1. 메모장 또는 파일 탐색기 창을 복원 상태로 놓습니다.
2. 제목 표시줄을 빠르게 옆으로 끌고 놓습니다. 창이 진행 방향으로 감속하며 이동해야 합니다.
3. 천천히 끌거나 크기를 변경하면 관성이 생기지 않아야 합니다.
4. 관성 중 창을 다시 클릭하거나 트레이에서 OFF를 선택하면 즉시 멈춰야 합니다.
5. 보조 모니터로 이동한 뒤 같은 동작을 반복합니다.

## 알려진 제약

- Windows 표준 이동 루프의 이동 시작·종료 이벤트를 보내지 않는 사용자 지정 드래그 창은 지원하지 않습니다.
- 승격된 프로그램, 보안 데스크톱 및 보호된 시스템 창은 Windows 권한 경계 때문에 이동되지 않을 수 있습니다. `SetWindowPos` 실패 시 해당 관성을 중지합니다.
- 최대화·최소화·전체 화면 및 제목 표시줄이 없는 창은 제외합니다. Windows Snap으로 크기가 바뀐 창도 제외합니다.
- 저수준 마우스 훅은 시스템이 콜백 시간 초과로 제거할 수 있습니다. 이 경우 프로그램을 다시 실행해야 합니다.
